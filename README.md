# MateLink 校园靠谱组队平台 Demo

MateLink 是一个面向校园大作业、竞赛和创新创业项目的组队平台原型。Demo 展示了从校内登录、发布任务、申请项目、建立契约、AI 监工提醒到盈利模式说明的完整闭环。

## 功能亮点

- 校内模拟登录：生成模拟学号并同步学生画像
- 组队大厅：发布任务、展示项目卡片、申请加入项目
- 个人介绍与附件：申请项目时提交自我介绍和附件名称
- 契约中心：基于申请记录建立契约并锁定保证金
- AI 监工：节点提醒、群聊看板、右上角通知栏
- 数据看板：展示问卷痛点、功能期待和靠谱分趋势
- 答辩模式：自动播放完整动画演示，并展示盈利模式

## 技术栈

- React
- Vite
- Recharts
- Lucide React
- CSS 响应式布局与动画
